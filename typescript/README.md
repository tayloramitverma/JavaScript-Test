# TypeScript track

Separate from the JavaScript interview exercises in [`../javascript/`](../javascript/).

## Commands (from repo root)

```bash
npm run ts:build    # compile src/ → build/
npm run ts:watch    # watch mode
```

## Browser

1. Run `npm run ts:build`
2. Open `typescript/index.html` and check the console

## Layout

```text
typescript/
├── src/          # .ts source only
├── build/        # generated (gitignored)
├── tsconfig.json
└── index.html
```
